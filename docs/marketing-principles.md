## 1. 集客の基本原則

あらゆる媒体（LP・SNS・チラシ等）で成果を出すための4つのポイント。

- **ターゲット**: 誰に届けるか
- **ベネフィット**: その人にどんな価値（未来）を提供するか
- **根拠**: なぜそれを信じられるのか（証拠）
- **タイミング**: 上位戦略に属し、LP単体でのコントロールは難しいが非常に重要（媒体・配信時期・見込み客の検討段階）

タイミングを除く3つを押さえるだけで、デザインの質に関わらず問い合わせや発注を増やすことができる。戦略提案では、タイミングを完全に操作できないことを理解したうえで、媒体・配信時期・見込み客の検討段階も考慮する。

## 2. 戦略の階層

マーケティングにはピラミッド型の階層があり、下位のテクニック（文章術など）よりも上位の戦略（どのメディアを使うか、人間関係など）の方が効果が高い。

優先すべき上位戦略：
- 誰に届けるか
- どの媒体を使うか
- どんな関係性があるか
- なぜこの事業を行うのか
- 既存顧客との関係をどう深めるか

## 3. 理念・人間関係

ビジネスの本質は周りの人と仲良くなること。マダナイの発信では、単なる機能説明よりも、

- なぜこの事業をしているのか
- どんな未来を作りたいのか
- 顧客とどんな関係を築きたいのか

を重視し、共感と信頼につなげる。SNSなどで経営理念・ビジョンを語ることが、最も共感を生みファンを作る。

## 4. 新規獲得とリピート

新規顧客の獲得コストはリピートの5倍以上かかる。新規獲得だけでなく、LINE・メール・保守・継続支援・再購入・紹介など、顧客との継続的な関係を作る設計を考慮する。

## 5. LPの基本構造

効果的なLPを構成する基本要素：

1. **キャッチコピー**: 読者の興味を惹く言葉
2. **イメージ画像**: キャッチコピーを補足するビジュアル
3. **サービス・商品の内容**: 具体的な詳細情報
4. **申し込みフォーム**: 出口の設置

ただし、ユーザーの認知段階に応じて冒頭構成を変える（8章参照）。

## 6. ターゲット設定

不特定多数ではなく、特定の1人（ペルソナ）に向けて手紙を書くように文章を作成するのが最も効果的。戦略提案時は、以下まで具体化する。

- 誰が
- どんな状況で
- 何に困り
- 何を不安に感じ
- どんな未来を望むか

## 7. ベネフィット

顧客がどう変わるか（未来）を重視する。機能・スペックの説明で終わらせない。

ベネフィットは複数視点で抽出する：
- 感情的ベネフィット
- 機能的ベネフィット
- 経済的ベネフィット
- 時間的ベネフィット
- 社会的ベネフィット

顧客がどう変わるかを50個から100個書き出すことが推奨される。これにはAI（ChatGPTなど）を活用し、オズボーンのチェックリストやマンダラートの理論に基づいた抽出が有効。

## 8. 根拠

ベネフィットには必ず根拠を組み合わせる。根拠のない断定は禁止する。

根拠の例：
- 実績・お客様の声・事例
- 写真・制作ストーリー（プロセスエコノミー）
- 担当者の経験・専門性
- 比較・数値・仕組み・第三者評価

## 9. 抽象と具体

心に刺さる文章を書くには、「抽象」と「具体」の使い分けが重要。

- **抽象（感情を動かす）**: 「家族と過ごす時間を増やしませんか？」のように、ベネフィットを広義に捉えて感情に訴える
- **具体（論理を納得させる）**: 「残業を毎月30時間削減」のように、スペックや数字で説得力を高める

基本構成：**抽象で惹きつける → 具体で納得させる → 再び未来を見せる → 行動を促す**

## 10. 社会的証明

実績・お客様の声・導入事例・写真・数字・権威性を、信頼のために活用する。存在しない実績や声を作らない。証拠がない場合は、必要な根拠として（今後集めるべきものとして）提案するだけにとどめる。

## 11. 新しさ（クーリッジ効果）

「リニューアル」「新登場」といった言葉は、それだけで人の心を動かす。ただし事実である場合だけ使用する。

## 12. 価格の見せ方

価格は単独で見せず、以下と合わせて説明する：
- 何が含まれるか
- どんな未来が得られるか
- 他の選択肢との違い
- 追加料金の有無
- 安心材料

競合より高い場合は価格を下に配置し、円マークを外したり漢数字を使ったりして「お金」の意識を和らげる工夫が有効。ただし価格を不自然に隠したり、誤認させる表現は使わない。

## 13. SEO

B2Bビジネスやニッチサービスの場合、ブログやホームページで小さなニーズをたくさん集める「ロングテールSEO」の手法が非常に有効。大きなキーワードだけでなく、具体的な悩みや用途を拾う。ブログ・FAQ・事例・地域・業種別ページなど、小さな検索意図を積み上げる。

## 14. SNS導線

SNS投稿は役割を分ける：
- 拡散を狙う投稿
- 信頼を作る投稿
- 商品理解を深める投稿
- 行動を促す投稿

SNSはリンクを貼ると拡散力が下がるため、バズる投稿とは別に、プロフィール・固定投稿・コメント欄・LINEなどへ自然に誘導する導線を作る。

## 15. 認知段階に合わせる

読み手がすでに知っていることを、最初から繰り返さない。

認知段階の例：
- 未認知 → 課題認知 → 解決策認知 → サービス認知 → 比較検討 → 購入直前 → 既存顧客

やってはいけない例：
- 既にマダナイを知る人へ長い自己紹介をしない
- サービスを理解している人へ「〇〇とは？」から始めない
- 既に共感済みの人へ、再び悩みの列挙だけをしない
- ビジュアルが重要な商品なのに文字だけで説明しようとする

## 16. ビジュアル

見た目が重要なサービスでは、文章だけで説明せず、制作事例・画面・写真・ビフォーアフター・図解・イメージを使う提案をする。

## 17. 心理学の扱い

カーネマンの「システム1・システム2」やサイモン・シネックの「ゴールデンサークル（Whyから始める）」などの考え方を参考にしてよいが、心理学用語を乱用しない。表面的なテクニックではなく、読み手の理解・感情・意思決定を助ける目的で使用する。

## 戦略提案への反映

戦略候補を提案する際は、単に「共感型」「比較型」などの名称を出すだけでなく、各候補について以下を分析する。

- ターゲット
- 認知段階
- 中心ベネフィット
- 必要な根拠
- 狙う心理
- 適した媒体
- 適したタイミング
- 抽象と具体の使い分け
- CTAまでの流れ
- リピートや継続導線

おすすめ戦略の選定理由にも、これらの原則を使う。

## 生成物への反映

PDF・LINE・SNS・LPを生成する際は、必ず以下の整合性を確認する。

```
ターゲット → 悩み → ベネフィット → 根拠 → 構成 → CTA
```

ターゲットとベネフィット、ベネフィットと根拠、内容とCTAがずれていないかを検証する。

## 禁止事項

- 存在しない実績やお客様の声を作る
- 根拠のない数字を出す
- 成果を保証する
- 認知段階を無視して同じ型を使う
- 「こんなお悩みありませんか？」を毎回機械的に使う
- 機能説明だけで終わる
- 抽象表現だけで具体性がない
- 具体情報だけで感情や未来がない
- どの業種にも同じ文章を出す
- 心理学用語を権威付けのためだけに使う

## 品質チェック

生成後、内部的に以下を確認する。

1. 誰向けか明確か
2. ベネフィットが未来として伝わるか
3. 根拠が不足していないか
4. 抽象と具体が両方あるか
5. 認知段階に合っているか
6. 同じ説明を繰り返していないか
7. CTAが自然か
8. 継続・リピート導線も考慮されているか
9. 根拠のない断定がないか
10. マダナイが単なる制作会社に見えていないか

## 既存プロンプトへの統合方針

この知識を追加しても、既存のマダナイブランド情報やNG表現は削除しない。プロンプト内の情報の優先順位は以下のとおり（矛盾する場合は番号の若い方を優先する）。

1. 安全性・事実性
2. ユーザー入力
3. マダナイのブランド
4. このマーケティング原則
5. 選択済み戦略
6. 各媒体の出力ルール

長文をプロンプトへ直接埋め込むと費用・応答速度に影響するため、Claude APIへ渡すのは要点版（[`lib/ai/marketing-principles.ts`](../lib/ai/marketing-principles.ts)）とし、完全版はこのファイルにのみ保持する。
